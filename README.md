## Contents of each case-study folder
Each folder contains:
- `case_study.md` - problem statement, objectives, assumptions, algorithm, pseudocode, test cases, and conclusion.
- `solution.py` - runnable Python solution.
- `flowchart.png` - simplified flowchart for the program logic.
- `test_cases.csv` - test scenarios and expected results.
- `sample_output.txt` - text output from the sample execution.
- `output_screenshot.png` - screenshot-style capture of that sample execution.

## Running a program
1. Install Python 3.
2. Open a terminal in the required case-study folder.
3. Run `python solution.py` (on some systems use `py solution.py`).
4. To try another test case, edit the sample lists/tuples near the top of `solution.py` and run it again.

## Syllabus approach
The solutions use beginner-level Python constructs: variables, numeric and string data, operators, conditional statements, loops, strings, lists, nested lists, tuples, tuple unpacking, and basic list operations. They do not require third-party packages.
